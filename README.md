## 🌟 About The Project

**Caffeina** is a modern landing page concept for a cozy coffee brand. It combines a warm earthy palette, elegant serif headings, smooth scroll animations and a clean layout, so every visitor feels like they are walking into a real café.

> *"More than coffee, it's a feeling."*

## ✨ Features

| | Feature | Details |
|---|---|---|
| 🎨 | **Beautiful Design** | Warm coffee-inspired color palette with a cream background |
| 📱 | **Fully Responsive** | Optimized for desktop, tablet and mobile (breakpoints: 1000px, 700px, 380px) |
| 🎞️ | **Scroll Animations** | Smooth reveal effects using the `IntersectionObserver` API |
| 🍔 | **Pure CSS Mobile Menu** | Hamburger menu built with the checkbox trick, no JS needed |
| 🫧 | **Floating Elements** | Animated floating card and rotating-style "EST. 2026" stamp |
| 🍵 | **Menu Cards** | Elegant product cards with images, prices and "Best Seller" badge |
| ♿ | **Accessible** | Respects `prefers-reduced-motion` for motion-sensitive users |
| ⚡ | **Lightweight** | No frameworks, no libraries, super fast loading |

## 🧩 Page Sections

- 🧭 **Navbar**: sticky header with logo, links and an "Order Now" button
- 🦸 **Hero**: catchy headline, call-to-action buttons and a floating info card
- 🌱 **Features Strip**: organic beans, expert roasting, made with love, quick delivery
- ☕ **Menu**: Cappuccino, Iced Coffee and Classic Latte cards
- 📖 **Our Story**: brand story with an image and a passion badge
- 💌 **Contact / CTA**: final call-to-action section
- 🦶 **Footer**: brand info, quick links and contact links

## 🚀 Getting Started

### Run locally

```bash
# 1. Clone the repository
git clone https://github.com/ansari-developer/caffeina-coffee-website.git

# 2. Go into the folder
cd caffeina-coffee-website

# 3. Open index.html in your browser
```

Bas! Kisi installation ya build tool ki zaroorat nahi. 🎉

### Deploy on GitHub Pages

1. Repository ki **Settings** kholo
2. **Pages** section me jao
3. Source me **Deploy from a branch** select karo
4. Branch: **main** / folder: **/(root)** → **Save**
5. Kuch minute baad site live ho jayegi 🚀
